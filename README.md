# FreezeezyPeak-StudioDev-Test-MonoGame

**English:** MonoGame test projects. Experiments and practice for different concepts.

**Español:** Tests de MonoGame. Experimentos y práctica de diferentes conceptos.

---

## Sobre este repositorio / About this repository

**Español:** Cada carpeta es un proyecto independiente de prueba. Los tests se crean para aprender, probar ideas y practicar. Algunos son educativos, otros son experimentos rápidos y pueden no estar terminados.

**English:** Each folder is an independent test project. Tests are created to learn, try ideas, and practice. Some are educational, others are quick experiments and may be unfinished.

## Requisitos / Requirements

- .NET SDK (versión 8 o superior / version 8 or higher)
- MonoGame (DesktopGL)
- Visual Studio, VS Code o Rider / Visual Studio, VS Code or Rider

## Cómo ejecutar un test / How to run a test

**Español:**
1. Entrá a la carpeta del test que quieras probar.
2. Ejecutá `dotnet build` para compilar.
3. Ejecutá `dotnet run` para abrir la ventana.

**English:**
1. Open the folder of the test you want to try.
2. Run `dotnet build` to compile.
3. Run `dotnet run` to open the window.

## Convenciones / Conventions

- Cada test tiene su propio `.csproj` y no depende de los otros.
- Los nombres siguen el formato `Test-XXXXX-Tema`, donde `XXXXX` es un número secuencial.
- Los assets (`Content/`) pertenecen a cada test, no se comparten.
