## 🇬🇧 English

MonoGame test projects. Experiments and practice for different concepts.

### About this repository
Each folder is an independent test project. Tests are created to learn, try ideas, and practice. Some are educational, others are quick experiments and may be unfinished.

### Requirements
- .NET SDK (version 8 or higher)
- MonoGame (DesktopGL)
- Visual Studio, VS Code or Rider

### How to run a test
1. Open the folder of the test you want to try.
2. Run `dotnet build` to compile.
3. Run `dotnet run` to open the window.

### Conventions
- Each test has its own `.csproj` and does not depend on the others.
- Names follow the format `Test-XXXXX-Topic`, where `XXXXX` is a sequential number.
- Assets (`Content/`) belong to each test and are not shared.

### License
Check each test's license inside its folder.
